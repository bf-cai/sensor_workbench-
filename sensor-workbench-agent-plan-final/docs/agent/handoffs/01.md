## Contracts

- `GET /api/v1/health`, `/sources`, `/clock-domains`; `WS /api/v1/stream`.
- Health references a nullable `stream_schema` to expose WebSocket schemas through
  OpenAPI. Generate/check with `make generate-api` / `make check-api`.
- Timestamp fields are Python integers; JSON uses decimal strings to preserve
  precision in JavaScript. Raw/sample and host receive clocks remain separate.
- Source identity survives reconnect; process `run_id` distinguishes restarts,
  event identities, and synthetic clock epochs. Host monotonic time requires boot ID.
- Source rate is 10 Hz. Synthetic triangular delay is 10000–15000 ns and explicitly
  carries simulation labels. No physical synchronization metric is measured.
- Per-client queues hold 32 observations, with at most 16 subscribers. Queue
  evictions are reported as connection-cumulative `dropped_total`; missed producer
  slots produce sequence gaps. Acquisition does not depend on browsers.
- Default bind is `127.0.0.1:8765`; non-loopback settings are rejected. Foreign
  WebSocket browser origins are rejected. Remote viewing uses an SSH tunnel.
- No database, recordings, hardware integrations, or migrations were introduced.
